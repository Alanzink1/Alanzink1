## About me

Sou desenvolvedor com foco em **Full-Stack Development**, trabalhando atualmente com **Angular + TypeScript no front-end** e **Lazarus / Free Pascal no back-end**.

Tenho base e projetos com **Node.js**, principalmente envolvendo **APIs REST e aplicações full stack**, e atualmente estou estudando **Flutter + Dart** para expandir meu desenvolvimento para aplicações multiplataforma.

Gosto de trabalhar além da interface: entender regra de negócio, arquitetura, integração entre camadas, banco de dados e o produto que está sendo construído.
